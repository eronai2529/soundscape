# Navilens use documentation

## Summary 
testing the use of navilens codes from free educational navilens package

## General notes
Navilens codes are read precisely as they are labeled in the navilens app.
These codes were printed on letter size matte paper on RPI's li238cl printer, a Richoh IM C2510 printer.
This test was run in daylight at approximately noon, indoors, in a well lit space with overhead lighting and adjacent to a nort facing windows. This simulates the conditions of the space the course will occur within.
