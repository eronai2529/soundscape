# Summary

Navilens codes were hung around the Rensselaer Polytechnic Institute campus in 5 locations. Generally, the codes work from a distance of atleast 50 ft away, though direct angles prove to me more effective than indirect ones.

### Russell Sage Hall

Cooridinates: 42.72989823, -73.67823186

![Russell Sage Hall Main Entrance](./CodeLocations/IMG_075.heic)

This code was hung at direct angle on a brick surface under covering. While the brick surface was uneven, making hanging more difficult, the laminated nature of the code allows it to stay even and readable. The covering above the code in combination with the its southern facing nature reduces glare. It is also placed in an area that has consistent lighting during opertating hours. 

![Russell Sage Hall Main Entrance 10 feet](./CodeLocations/IMG_076.heic)

At ~10~ feet, from a direct angle, this code was detected

At ~30~ feet, from a direct angle, this code was detected

![Russell Sage Hall Main Entrance 50 feet](./CodeLocations/IMG_078.heic)

At ~50~ feet, from a direct angle, this code was detected


### Low Center for Industrial Engineering

Cooridinates: 42.72967093, -73.67885401

![Low Center for Industrial Engineering](./CodeLocations/IMG_0179.heic)

This code was hung at a direct angle for those entering the building, but an indirect angle from the perspective of a passerby. The code being read at an angle reduces readability, but it is an inevitability for the way this building faces. The code was hung on a flat surface and south facing under a covering. While at certain angles, the sun will likely produce a glare off these codes, it is less likely in this case than an east or west facing code. The area is less well lit during nighttime which may pose a readability problem at certain hours.

![Low Center for Industrial Engineering 15 feet](./CodeLocations/IMG_0179.heic)

![Low Center for Industrial Engineering 30 feet](./CodeLocations/IMG_0178.heic)

At ~30 feet, from a steeper angle, this code was detectable

### Ricketts Building

Cooridinates: 42.73078602, -73.67978698

![Ricketts Building](./CodeLocations/IMG_0183.heic)

This code was hung at an indirect angle on a flat surface. This location was suboptimal and option of placing it on the door rather than brick remains. Additionally, it is placed on an east facing surface which may create problems with glare at certain hours of the day. The area will recieve light at nighttime through the glass door, which might not occur if it were placed on the door. Additionally, the approach to Ricketts requires the ascent up stairs, which creates steeper angles at which the code must be read. Overall, it would be optimal to find a new space to place codes at Ricketts.

# Conclusion

Optimally, should be hung at direct angles in well lit areas. The surfaces they are hung on should be flat face north/south or the area should be covered. If operational constraints don't allow for this, other code locations will certainly work. Further testing of these codes must be completed at different times of the day and additional codes may be added for maximal readability at all times.
